# Lawyer Diary 2.1.0

First public connected Windows release.

- Windows installer with Start menu and desktop shortcuts.
- Firebase-connected cases, clients, hearing history and subscriptions.
- Email verification, password recovery and protected saved sessions.
- Automatic background download of signed updates, with restart when convenient.
- Earlier app retained during update recovery; tampered downloads rejected.
- Expired subscriptions retain reading and PDF export.
- Prototype bank details hidden. The owner will publish payment details separately.

## Installation

Download `LawyerDiary-Setup.exe`. Requires 64-bit Windows 10 or later and internet access.
The app installs for your Windows account without requiring administrator access.
Sign in using a verified email address. The app contains a public update-verification
key, never the owner's private release key or Firebase administrator credentials.

The installer and executable do not currently have a Windows publisher certificate.
Windows may show an unrecognized-publisher notice. Update manifests are separately
signed and checked by the app; this is not a Windows publisher signature.
